# Nihongo Dojo 🇯🇵

App para aprender japonés desde cero hasta el N4 (kana, kanji con orden de trazos, vocabulario, gramática, lectura y escucha) y reforzar el inglés A2–B1, con la interfaz en español.

## Descargar

**[⬇️ NihongoDojo.apk](https://raw.githubusercontent.com/Vikzeth/nihongo-dojo/main/NihongoDojo.apk)** · Android 7 o superior

1. Abre el enlace en el teléfono y descarga el archivo.
2. Ábrelo. Si Android lo pide, permite «Instalar apps desconocidas» para tu navegador.
3. La primera vez puedes empezar desde cero o hacer la prueba de nivel para desbloquear lo que ya sabes.

Las actualizaciones llegan desde la propia app (aviso en Inicio, o Ajustes → Actualizaciones). Tu progreso se guarda solo en tu teléfono, con una copia diaria en `Descargas/NihongoDojo`.

Este repositorio solo contiene el APK y `update.json` (la versión publicada).
